# Contributing to FrankieXGM

Bug reports, compatibility reports, testing results, and code contributions
are welcome.

## Before submitting a bug

Please include, where possible:

- FrankieXGM version
- Operating system
- VGM version
- Whether the input is VGM or VGZ
- NTSC or PAL setting
- PCM normalization/gain setting
- A description of the audible or technical problem
- The relevant FrankieXGM log output

If you can redistribute the test VGM, attaching a small reproducible example
is especially useful.

## Pull requests

Please keep changes focused and preserve the existing command-line behavior
unless the change intentionally modifies it.
